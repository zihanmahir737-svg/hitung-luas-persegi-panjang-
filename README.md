## 🚀 COMPILER C++

Kamu dapat menulis, menjalankan, dan menguji program C++ langsung melalui browser tanpa memasang aplikasi compiler di komputer.

**[BUKA COMPILER C++](https://heruruhanda.github.io/template-tugas-pseudocode/)**

### Petunjuk Menggunakan Compiler

1. Klik tautan **Buka Compiler C++** di atas dengan cara klik kanan lalu pilih open link new tab.
2. Pastikan bahasa yang dipilih adalah C++.
3. Tulis atau tempel kode program pada bagian editor sebelah kiri.
4. Klik tombol **Run** untuk menjalankan program.
5. Periksa hasil program pada bagian Output di sebelah kanan.
6. Jika program membutuhkan masukan, masukkan data melalui bagian `stdin`, kemudian klik Run.

### Menyimpan Program dengan My Code

1. Klik menu **My Code** di bagian kanan atas compiler.
2. Gunakan fitur penyimpanan untuk menyimpan program dengan nama yang mudah dikenali.
3. Untuk membuka kembali program, klik **My Code**, kemudian pilih program yang sudah disimpan.

**Catatan:** My Code menyimpan program di browser dan perangkat yang digunakan. Penyimpanan ini bukan pengganti pengumpulan tugas melalui GitHub.

### Memindahkan Kode Akhir ke GitHub

Setelah program selesai dan berhasil diuji:

1. Salin kode program dari editor compiler.
2. Buka repository tugas GitHub milikmu.
3. Masuk ke folder `source-code`.
4. Buka file `main.cpp`.
5. Klik tombol edit (ikon pensil).
6. Ganti kode contoh dengan kode program milikmu.
7. Klik **Commit changes** untuk menyimpan perubahan.

Tuliskan algoritma dan pseudocode pada file:

`pseudocode/algoritma.txt`

Pastikan pseudocode dibuat sebelum menulis kode program C++.

## D. IMPLEMENTASI PROGRAM

Tuliskan kode program C++ pada file:

`source-code/main.cpp`

Ketentuan:
- Gunakan bahasa pemrograman C++.
- Program harus dapat dijalankan tanpa kesalahan.
- Gunakan variabel, input, proses, dan output sesuai kebutuhan.
- Gunakan percabangan atau perulangan jika diperlukan.

## E. PENGUJIAN PROGRAM

Lakukan pengujian program dan dokumentasikan hasilnya pada:

`dokumentasi/pengujian.md`

Ketentuan pengujian:
- Lakukan minimal 3 skenario pengujian.
- Tuliskan input yang digunakan.
- Tuliskan hasil yang diharapkan.
- Bandingkan dengan hasil aktual.
- Catat kesalahan dan perbaikannya jika ada.
- Lampirkan screenshot hasil program pada `dokumentasi/hasil-program.png`.
